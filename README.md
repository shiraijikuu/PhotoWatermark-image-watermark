# PhotoWatermark - image-watermark plugin / 图片水印插件

**EN:** A plugin for Photo Watermark that stamps a custom image as a watermark.
**中文：** 给 Photo Watermark 添加"自定义图片水印"的插件。

## Features / 功能

- Custom image watermark (PNG / JPG / GIF) / 自定义图片水印（支持 PNG/JPG/GIF）
- **Built-in preset watermarks (10 GIFs)** / **内置预设水印图（10 张 GIF）**
- GIF uses the first frame only (static, not animated) / GIF 取第一帧静态显示，不播放动画
- Adjustable size (% of image width), position (9 positions), rotation, opacity / 大小、位置、旋转、不透明度可调
- Auto-skips RAW photos to avoid slow processing / RAW 自动跳过，避免加载过久

## Install / 安装

1. Download this plugin folder / 下载本插件文件夹
2. Put it into the plugins/ directory next to PhotoWatermark.exe / 放入 PhotoWatermark.exe 旁的 plugins/ 目录
3. Restart the app / 重启软件

## Usage / 使用

1. Export tab -> Plugin Settings -> image-watermark / 「导出」页 ->「插件设置」-> image-watermark
2. Pick a **preset** or choose your own image, then set size / position / rotation / opacity, save / 选择**预设**或自定义图片，调整大小/位置/旋转/不透明度，保存
3. Style tab -> Watermark Style -> 图片水印（插件）/ 「样式」页 ->「水印样式」->「图片水印（插件）」
